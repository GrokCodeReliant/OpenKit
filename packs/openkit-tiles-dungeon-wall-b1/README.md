# openkit-tiles-dungeon-wall-b1

12 CC0 2D dungeon wall tiles, 256x256 RGBA PNG, medieval dungeon palette (cool stone greys, mortar, moss, iron). Companion to openkit-tiles-dungeon-floor-b1.

- 8 seamless tiles (wrap on both axes): stone plain (ashlar), stone rough, brick, worn brick, cobble, moss, cracked plaster, wood panel.
- 4 accents: torch sconce (opaque), door arch (alpha opening), grate / barred window (alpha opening), empty banner hook.

Layout: `tiles/` PNGs, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`.
