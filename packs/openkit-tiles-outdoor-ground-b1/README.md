# openkit-tiles-outdoor-ground-b1

12 game-ready 2D outdoor ground tiles, 256x256 RGBA PNG, CC0-1.0.
Complements openkit-tiles-dungeon-floor-b1 and openkit-tiles-dungeon-wall-b1.

- Seamless (10): grass-lush, grass-dry, dirt-path, dirt-mud, sand-shore, stone-path, cobble-road, water-shallow, water-deep, snow-ground
- Accent (2, alpha edges): flower-patch, rock-cluster

Layout: `tiles/`, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`.
