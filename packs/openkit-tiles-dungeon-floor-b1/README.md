# openkit-tiles-dungeon-floor-b1

12 CC0 2D dungeon floor tiles, 256×256 RGBA PNG, medieval-fantasy palette (cool greys, moss, dirt, worn stone, wood).

- 9 seamless tiles (wrap on both axes): stone flag plain/cracked, cobble, brick floor, packed dirt, gravel, mossy stone, plank floor, worn planks.
- 3 accents: drain grate (opaque), rubble patch (alpha), bloodstain overlay (mostly transparent).

Files: `tiles/*.png`, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`. License: CC0-1.0.
