# openkit-tiles-water-b1
16 game-ready 2D water and shore tiles, 256x256 RGBA PNG, CC0-1.0. Flat fantasy style with dark outlines, matching the other Open Kit tile packs.

- Seamless water: water-calm, water-ripple, water-foam, river-center, ice-sheet, marsh-reed (pond-lily, ice-crack semi-seamless)
- Directional edges: water-foam-edge, river-bank-left, river-bank-right, waterfall-top, waterfall-mid, waterfall-splash
- Structures over water: bridge-plank-over-water, pier-plank

Layout: `tiles/`, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`.
