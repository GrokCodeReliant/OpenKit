# openkit-ui-slots-badges-b1

16 CC0 2D UI PNGs (RGBA, transparent): inventory slot frames (empty/locked/rare/epic/legendary, 96x96), rarity badges (common to legendary, 64x64), corner ornament, thin divider, progress bar bg/fill (256x24), minimap and portrait frames (128x128, transparent centre).
Complements openkit-ui-frames-b1 (same wood/parchment/gold palette, no overlapping filenames). No baked text.

Layout: `ui/`, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`.
