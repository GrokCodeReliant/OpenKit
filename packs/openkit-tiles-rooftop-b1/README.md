# openkit-tiles-rooftop-b1

12 game-ready 2D roof and building-exterior tiles, 256x256 RGBA PNG, CC0-1.0.
Pairs with outdoor-ground and dungeon floor/wall tile packs. Separate from the 3D roof-tiles FBX pack.

- Seamless (8): thatch, thatch ridge, slate, slate ridge, clay, wood shake, stucco wall, timber-frame wall
- Accent (4): chimney brick (opaque), shuttered window, wooden door, eave ornament (transparent backgrounds)

Layout: `tiles/`, `sheet/CONTACT_SHEET.png`, `MANIFEST.json`.
